# 02 审计

## 核心思路

审计不是背“检查清单”，而是回答：哪里可能错 → 为什么可能错 → 我要取得什么证据 → 证据够不够 → 最终报告怎么表达。

## 推荐学习顺序

1. 审计目标、认定、重要性、审计风险；
2. 风险评估 → 风险应对，建立风险导向审计主线；
3. 审计证据、函证、监盘、分析程序、审计抽样；
4. 销售与收款、采购与付款、生产与存货、货币资金等业务循环；
5. 特殊事项；
6. 完成审计与审计报告；
7. 内部控制审计；
8. 职业道德、质量管理、可持续信息鉴证。

## 做题要求

简答题不能只背关键词。回答至少包含：判断/结论 → 原因 → 应采取的程序或影响。
