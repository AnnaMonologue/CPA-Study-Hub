## 本章主线

先判断投资者对被投资单位拥有哪一种权力关系：

- 控制 → 子公司投资 → 个别财务报表通常采用成本法；
- 共同控制 → 先判断属于共同经营还是合营企业；合营企业投资通常采用权益法；
- 重大影响 → 联营企业投资 → 权益法；
- 三者均无 → 通常进入金融工具准则范围。

关系判断完成后，再处理取得成本、后续损益和处置。

## 高频失分点

- 只按持股比例判断控制或重大影响；
- 同一控制与非同一控制下对子公司投资的初始成本混用；
- 把企业合并发生的审计、法律等中介费用全部计入长期股权投资成本；
- 权益法下被投资单位宣告现金股利时继续确认投资收益；
- 权益法初始投资成本小于应享有可辨认净资产公允价值份额时漏调长期股权投资；
- 权益法直接按被投资单位账面净利润乘持股比例，不做必要调整；
- 核算方法转换时只处理新增或处置部分，漏掉原投资的追溯调整、重新计量或累计其他综合收益处理；
- 把共同经营和合营企业按同一方法处理。

禁止：看到“持股 20%、50%、60%”直接选核算方法。先判断实际权力关系。
