# 05 核算方法转换与处置

## 结论

核算方法转换题的核心是“投资关系发生了什么变化”。先判断转换后的关系，再处理原投资和新增/处置部分。

常见路径：

- 公允价值计量 → 权益法；
- 权益法 → 公允价值计量；
- 权益法 → 成本法；
- 成本法 → 权益法；
- 成本法 → 公允价值计量；
- 部分或全部处置长期股权投资。

## 1. 公允价值计量 → 权益法

场景：原来只持少量股份，没有重大影响，按金融工具准则计量；追加投资后形成重大影响或共同控制。

核心步骤：

1. 确定原金融资产在转换日的账面/公允价值；
2. 加上新增投资成本，形成权益法下新的初始投资成本；
3. 按原金融资产分类处理此前累计公允价值变动或其他综合收益；
4. 比较新的初始投资成本与应享有可辨认净资产公允价值份额；
5. 转入权益法后开始确认损益调整等。

原投资如果属于以公允价值计量且其变动计入其他综合收益的权益工具，累计其他综合收益的处理遵循金融工具准则，通常与该类权益工具终止确认规则一致。

不可：把所有金融资产原累计其他综合收益统一转入投资收益。

## 2. 权益法 → 公允价值计量

场景：出售部分股权后，对被投资单位不再具有共同控制或重大影响，剩余股权进入金融工具准则范围。

核心步骤：

1. 对出售部分确认处置损益；
2. 剩余股权按转换日公允价值计量；
3. 剩余股权公允价值与其原账面价值之间的差额通常计入当期损益；
4. 原权益法形成的其他综合收益和其他权益变动按相关规则处理。

处置损益的直观框架：

`处置价款 - 被处置部分长期股权投资账面价值`

剩余股权还要单独做公允价值重新计量。

## 3. 权益法 → 成本法

场景：原来是联营/合营投资，追加投资后取得控制权。

个别财务报表中，追加投资日通常以：

`原权益法投资账面价值 + 新增投资成本`

作为按成本法核算的长期股权投资初始成本基础。

原权益法期间确认的其他综合收益、其他权益变动，通常不在取得控制权当天简单一次性结转；后续处置时按相关准则处理。

企业合并是否属于同一控制，还会影响取得控制权时的具体计量。本章先掌握转换框架，后续企业合并章节继续深化。

## 4. 成本法 → 权益法

场景：原来控制子公司，出售部分股权后丧失控制，但剩余股权仍能施加重大影响或形成共同控制。

个别财务报表常见处理重点：

1. 对出售部分确认处置损益；
2. 剩余投资改按权益法；
3. 对剩余股权从取得投资时点开始进行权益法追溯调整，考虑应享有净资产变化、其他综合收益和其他权益变动等；
4. 相关追溯调整根据发生期间影响投资收益、留存收益、其他综合收益或资本公积等项目。

这一类题常把“以前年度净利润”和“本年度净利润”分开给出，目的是测试留存收益与当期投资收益的区分。

## 5. 成本法 → 公允价值计量

场景：原来控制子公司，出售股权后丧失控制，同时对剩余股权也不再具有共同控制或重大影响。

个别财务报表核心：

1. 对出售部分确认处置损益；
2. 剩余股权按转换日公允价值重新计量；
3. 剩余股权公允价值与原账面价值之间的差额通常计入当期投资收益；
4. 此后剩余股权按金融工具准则核算。

## 6. 长期股权投资部分处置但关系不变

如果只出售一小部分股权，处置后仍保持原核算关系，通常按被处置部分的账面价值计算处置损益。

例：长期股权投资账面价值 1,000 万元，出售其中 20% 对应份额，收到 260 万元，处置后仍保持重大影响。

简化情况下，被处置部分账面价值：

`1,000 × 20% = 200 万元`

处置收益：

`260 - 200 = 60 万元`

具体题目若长期股权投资明细较复杂，还要按教材要求结转相应明细。

## 7. 全部处置

全部处置长期股权投资时，基础框架：

`处置损益 = 取得价款 - 长期股权投资账面价值`

权益法下还要检查历史累计项目：

- 其他综合收益；
- 资本公积——其他资本公积。

其后续结转必须遵循相关项目原本的会计处理基础。

### 其他综合收益

如果底层项目以后本来可以重分类进损益，则处置投资时按规则结转。

如果底层项目属于以后不得重分类进损益的项目，则按其原规则处理，可能转入留存收益。

### 其他权益变动

权益法确认在资本公积——其他资本公积中的累计金额，在处置相关投资时按准则规定处理，常见考试处理中转入当期损益。

## 8. 转换题统一做题框架

每道转换题先写五行：

1. 转换前关系；
2. 转换后关系；
3. 转换前核算方法；
4. 转换后核算方法；
5. 原投资是否要追溯调整或重新计量。

再处理金额。

不可：看到“出售 10% 股权”立即写处置分录。出售后的控制、共同控制或重大影响状态决定整道题的会计处理。
