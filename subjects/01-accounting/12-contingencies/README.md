# 第十二章 或有事项

## 本章目标

完成本章后，应能判断一项不确定事项应确认预计负债、仅披露或不作处理，并能计算预计负债、处理第三方补偿、亏损合同、重组义务以及未决诉讼等典型业务。

2026 CPA 会计大纲将本章分为概述、确认与计量、具体应用和列报，整体以能力等级 2 为主。

## 学习顺序

1. [`01-recognition-and-measurement.md`](01-recognition-and-measurement.md)：或有事项、预计负债、或有负债、或有资产、最佳估计数和补偿。
2. [`02-applications-and-disclosure.md`](02-applications-and-disclosure.md)：未决诉讼、产品质量保证、亏损合同、重组义务和披露。
3. [`03-practice.md`](03-practice.md)：章节练习。
4. [`04-answers.md`](04-answers.md)：答案与错因分析。

## 本章主线

先判断是否已经形成现时义务，再判断经济利益流出是否很可能，最后判断金额能否可靠计量。

三个条件同时满足时确认预计负债：

1. 存在现时义务；
2. 履行义务很可能导致经济利益流出；
3. 金额能够可靠计量。

或有负债和或有资产通常不确认，只按准则要求考虑披露。

禁止：看到“可能赔钱”就直接确认预计负债。
