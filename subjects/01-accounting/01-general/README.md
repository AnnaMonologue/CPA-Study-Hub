# 第一章 总论

## 这一章解决什么问题

总论负责建立会计的规则框架。后续每个具体章节都要回到这里判断：为什么确认、按什么金额计量、什么时候进报表、信息应达到什么质量。

## 2026 大纲定位

本章包括：

1. 会计概述；
2. 财务报告目标、会计基本假设和会计基础；
3. 会计信息质量要求；
4. 会计要素及其确认和计量；
5. 财务报告；
6. 可持续信息披露；
7. 人工智能在会计审计领域的应用。

其中会计定义、作用偏基础理解；后半部分更重视规则应用。

## 学完应达到

- 能解释权责发生制为什么会导致“收入、利润、现金”不一致；
- 能在案例中判断会计主体、持续经营、会计分期和货币计量；
- 能区分可靠性、相关性、可比性、谨慎性、重要性、实质重于形式等质量要求；
- 能识别历史成本、重置成本、可变现净值、现值、公允价值；
- 能说明一套完整财务报告主要包含什么；
- 对可持续信息披露和 AI 应用知道考试关注的基本方向。

禁止：把总论背成一串定义。每个概念都要能放进具体业务判断。
