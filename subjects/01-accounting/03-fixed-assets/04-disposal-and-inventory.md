# 4. 固定资产处置与清查

## 一句话结论

固定资产退出企业时，要先清掉原价、累计折旧和减值准备，再把处置收入、税费和清理支出放进同一条计算链，最后确认处置损益。

## 一、固定资产出售

出售固定资产时，常通过“固定资产清理”归集。

### 第一步：转入清理

```text
借：固定资产清理
    累计折旧
    固定资产减值准备
贷：固定资产
```

“固定资产清理”此时记录的是处置前账面价值。

### 第二步：发生清理费用

```text
借：固定资产清理
贷：银行存款等
```

### 第三步：取得出售收入

```text
借：银行存款等
贷：固定资产清理
    应交税费——应交增值税（销项税额）
```

### 第四步：结转处置损益

正常出售、转让固定资产形成的净损益通常计入“资产处置损益”。

```text
借：固定资产清理
贷：资产处置损益
```

如果形成净损失，借贷方向相反。

## 二、处置损益的计算

可以先用一个统一公式：

`处置损益 = 不含税处置收入 - 固定资产账面价值 - 处置相关净支出`

其中：

`账面价值 = 固定资产原价 - 累计折旧 - 固定资产减值准备`

### 例 1

设备原价 100 万元，累计折旧 60 万元，无减值；不含税售价 50 万元，发生清理费用 2 万元。

账面价值：

`100 - 60 = 40 万元`

处置收益：

`50 - 40 - 2 = 8 万元`

确认资产处置收益 8 万元。

## 三、报废与毁损

固定资产因报废、自然灾害、意外事故等退出时，同样先通过“固定资产清理”归集账面价值和相关清理事项。

报废、毁损形成的异常净损失通常计入“营业外支出”；符合条件的残料收入、保险赔款和责任人赔偿应先从清理损失中扣除。

形成异常净收益时，按适用会计规则确认相应损益。

### 例 2

设备账面价值 30 万元，报废后取得残料 3 万元，保险公司赔偿 5 万元，发生清理费用 1 万元。

净损失：

`30 + 1 - 3 - 5 = 23 万元`

通常计入营业外支出。

## 四、终止确认条件

固定资产满足以下任一情形时，应终止确认：

- 处于处置状态；
- 预期通过使用或处置不能产生经济利益。

已经报废且不再产生经济利益的设备，不应继续长期挂在固定资产账面上。

## 五、固定资产盘亏

盘点发现固定资产短缺时，先按账面价值转入“待处理财产损溢”。

```text
借：待处理财产损溢
    累计折旧
    固定资产减值准备
贷：固定资产
```

查明原因并批准处理后：

- 应由责任人或保险公司赔偿的部分，确认其他应收款；
- 扣除赔偿后的净损失，通常计入营业外支出。

例如：

```text
借：其他应收款
    营业外支出
贷：待处理财产损溢
```

## 六、固定资产盘盈

固定资产盘盈属于重要前期差错处理思路。

通常通过“以前年度损益调整”核算，再调整留存收益等相关项目。

禁止：把固定资产盘盈直接走“待处理财产损溢”。

这与存货盘盈的处理逻辑不同，是高频选择题考点。

## 七、处置题的快速计算模板

看到处置题时先列四行：

1. 原价：多少；
2. 累计折旧和减值：多少；
3. 得到账面价值；
4. 处置收入减账面价值、再减相关清理净支出。

然后再判断损益性质：

- 正常出售、转让：重点考虑资产处置损益；
- 报废、毁损等异常退出：重点考虑营业外收支。

## 八、常见陷阱

1. 用原价直接与售价比较，漏掉累计折旧；
2. 漏掉固定资产减值准备；
3. 把含增值税的收款总额直接当处置收入；
4. 漏记清理费用；
5. 把出售收益记入营业外收入；
6. 固定资产盘盈误走待处理财产损溢。

考试中先算金额，再判断损益科目，正确率会高很多。
