# 第三章 固定资产

## 本章目标

完成本章后，应能独立处理固定资产从取得到退出企业的完整生命周期：

**确认 → 初始计量 → 折旧 → 后续支出 → 处置 → 清查。**

2026 CPA 会计大纲将固定资产确认列为基础理解，其初始计量、折旧、后续支出和处置主要要求达到应用层级。

## 本章主线

固定资产题目通常围绕三个数字展开：

- **原价**：资产最初确认多少；
- **累计折旧**：已经分摊了多少成本；
- **账面价值**：原价减累计折旧、再减减值准备后的金额。

处置题、改良题和减值后折旧题最终都会回到这三个数字。

## 高频失分点

- 可抵扣增值税进项税额误计入固定资产成本；
- 达到预定可使用状态后仍把不应资本化的支出计入成本；
- 折旧起止月份判断错误；
- 双倍余额递减法最后两年处理错误；
- 更新改造时漏掉被替换部分的账面价值；
- 出售固定资产和报废毁损固定资产的损益科目混淆；
- 固定资产盘盈误走“待处理财产损溢”。

禁止：只背“借固定资产、贷银行存款”这一类单一模板。题目会通过税费、安装、拆除义务、分期付款、更新改造等条件改变初始金额和后续处理。
