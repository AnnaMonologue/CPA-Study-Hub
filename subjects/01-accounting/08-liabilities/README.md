# 第八章 负债

## 本章目标

完成本章后，应能区分流动负债和非流动负债，处理短期借款、应付票据、应付账款、应交税费、长期借款、一般公司债券和可转换公司债券等常见负债。

2026 CPA 会计大纲把本章分为两部分：流动负债、非流动负债。

## 学习顺序

1. [`01-current-liabilities.md`](01-current-liabilities.md)：短期借款、应付票据、应付账款及其他常见流动负债。
2. [`02-taxes-payable.md`](02-taxes-payable.md)：应交税费和增值税会计处理的基础框架。
3. [`03-long-term-borrowings-and-bonds.md`](03-long-term-borrowings-and-bonds.md)：长期借款、一般公司债券、实际利率法。
4. [`04-convertible-bonds.md`](04-convertible-bonds.md)：可转换公司债券的负债与权益拆分。
5. [`05-practice.md`](05-practice.md)：章节练习。
6. [`06-answers.md`](06-answers.md)：答案与错因分析。

## 本章主线

负债题先问三件事：

1. 企业现在承担什么现时义务？
2. 这项义务预计什么时候清偿？
3. 初始确认后按什么金额继续计量？

流动负债重点在“发生、结算、科目归类”。

非流动负债重点在“货币时间价值、实际利率法、利息费用与账面价值变化”。

## 与后续章节的边界

- 职工薪酬：第九章单独学习；
- 借款费用资本化：第十一章单独学习；
- 金融负债与权益工具区分：金融工具章节继续深化；
- 租赁负债：租赁章节单独学习。

税率、税收优惠和增值税具体政策属于年度波动内容。目标考季为 2027，涉及具体税率和政策时标记 `待2027核验`。

## 高频失分点

- 把一年内到期与“原始期限一年以内”混为一谈；
- 商业折扣、现金折扣与应付账款入账金额处理混淆；
- 应付票据到期不能支付时转错科目；
- 增值税进项、销项和应交税费方向混乱；
- 债券利息费用直接等于票面利息；
- 实际利率法下忘记调整债券账面价值；
- 可转换债券全部确认为负债；
- 可转换债券权益成分以后期间反复按公允价值重估。
