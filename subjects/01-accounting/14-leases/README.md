# 第十四章 租赁

## 本章目标

完成本章后，应能识别合同是否包含租赁，确定租赁期，完成承租人使用权资产和租赁负债的初始及后续计量，判断出租人融资租赁/经营租赁，并处理转租赁和售后租回的基本逻辑。

2026 CPA 会计大纲中，本章主要内容均达到能力等级 3。

## 学习顺序

1. [`01-identification-and-term.md`](01-identification-and-term.md)：租赁识别、分拆与合并、租赁期和选择权。
2. [`02-lessee.md`](02-lessee.md)：承租人初始计量、后续计量、短期租赁和低价值资产租赁。
3. [`03-lessor.md`](03-lessor.md)：出租人融资租赁和经营租赁。
4. [`04-special-transactions.md`](04-special-transactions.md)：转租赁、生产商/经销商出租人、售后租回。
5. [`05-practice.md`](05-practice.md)：章节练习。
6. [`06-answers.md`](06-answers.md)：答案与错因分析。

## 本章主线

先确认合同是否让客户在一定期间内控制已识别资产的使用。

确认存在租赁后：

- 承租人通常确认使用权资产和租赁负债；
- 短期租赁和低价值资产租赁可按规定选择简化处理；
- 出租人继续区分融资租赁和经营租赁。

禁止：沿用旧准则思路，把承租人的普通经营租赁全部放在表外。
