# 第四章 无形资产

## 本章目标

完成本章后，应能处理无形资产从取得、研发、摊销到处置的完整流程。

2026 CPA 会计大纲对无形资产的确认、初始计量、研发支出、后续计量和处置均有明确要求，其中研发阶段与开发阶段划分、开发支出资本化条件属于重点。

2. [`02-r-and-d.md`](02-r-and-d.md)：内部研究开发支出的费用化与资本化。
3. [`03-subsequent-measurement.md`](03-subsequent-measurement.md)：使用寿命、摊销、净残值与减值。

## 本章主线

无形资产题目通常围绕四个判断：

1. 这项资源能不能确认为无形资产；
2. 初始成本是多少；
3. 研发支出何时可以资本化；
4. 后续是否摊销、从何时开始、摊销多少。

## 高频失分点

- 把企业内部研究阶段支出资本化；
- 开发阶段一开始就全部资本化；
- 把已经费用化的研发支出重新转回无形资产；
- 无形资产摊销起止月份套用固定资产规则；
- 使用寿命不确定的无形资产照常摊销；
- 忽略预计净残值通常为零；
- 出售、出租和报废的损益处理混淆。

禁止：看到“研发”“专利”“软件”就直接认定形成无形资产。确认和资本化都需要满足条件。
