# 第十三章 金融工具

## 本章目标

完成本章后，应能完成金融资产和金融负债分类、后续计量、减值、重分类、金融负债与权益工具区分、金融资产转移以及套期会计的基础判断。

2026 CPA 会计大纲中，本章大部分核心内容达到能力等级 3，是会计科目最重要的高难度章节之一。

## 学习顺序

1. [`01-classification.md`](01-classification.md)：金融资产和金融负债分类、重分类。
2. [`02-liability-vs-equity.md`](02-liability-vs-equity.md)：金融负债与权益工具区分、复合金融工具、永续债。
3. [`03-measurement-and-impairment.md`](03-measurement-and-impairment.md)：初始计量、后续计量、实际利率法、预期信用损失。
4. [`04-financial-asset-transfer.md`](04-financial-asset-transfer.md)：终止确认、继续确认和继续涉入。
5. [`05-hedge-and-disclosure.md`](05-hedge-and-disclosure.md)：套期会计、披露和保险合同概览。
6. [`06-practice.md`](06-practice.md)：章节练习。
7. [`07-answers.md`](07-answers.md)：答案与错因分析。

## 本章主线

先识别合同形成的权利和义务，再分类，再决定计量方式。

金融资产分类优先回答两个问题：

1. 企业管理该金融资产的业务模式是什么；
2. 合同现金流量是否仅为本金及以未偿付本金为基础的利息支付。

分类完成后再进入公允价值、摊余成本、其他综合收益以及减值处理。
