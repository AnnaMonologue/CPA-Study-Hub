# 2. 投资性房地产后续计量

## 一句话结论

投资性房地产后续计量有两种模式：成本模式和公允价值模式。

公允价值模式要求公允价值能够持续可靠取得。

## 一、成本模式

成本模式的后续处理与固定资产、无形资产逻辑接近。

建筑物通常计提折旧；土地使用权通常进行摊销；出现减值迹象时按相关资产减值规则处理。

### 基本逻辑

```text
成本
- 累计折旧或累计摊销
- 减值准备
= 账面价值
```

出租期间取得租金收入通常确认为其他业务收入，相关折旧或摊销通常计入其他业务成本。

## 二、公允价值模式

只有在有确凿证据表明投资性房地产的公允价值能够持续可靠取得时，企业才可以采用公允价值模式。

采用公允价值模式后：

- 不计提折旧；
- 不进行摊销；
- 资产负债表日按公允价值调整账面价值；
- 公允价值与原账面价值的差额计入当期“公允价值变动损益”。

### 例 1

某投资性房地产期初账面价值 1,000 万元，年末公允价值 1,120 万元。

年末增加：

`1,120 - 1,000 = 120 万元`

处理：

```text
借：投资性房地产——公允价值变动 1,200,000
贷：公允价值变动损益             1,200,000
```

## 三、公允价值下降

如果年末公允价值低于账面价值，差额计入当期公允价值变动损失。

例如账面价值 1,000 万元，年末公允价值 930 万元：

```text
借：公允价值变动损益              700,000
贷：投资性房地产——公允价值变动    700,000
```

## 四、成本模式改为公允价值模式

当公允价值能够持续可靠取得，企业可以从成本模式改用公允价值模式。

这种改变属于会计政策变更，通常按会计政策变更的相关规则处理，转换日公允价值与原账面价值的差额调整期初留存收益等项目。

禁止：把成本模式改公允价值模式的转换差额简单计入当期公允价值变动损益。

## 五、公允价值模式改回成本模式

通常不允许从公允价值模式改回成本模式。

这一限制用于提高会计信息可比性，防止企业根据市场波动随意切换计量模式。

## 六、同一企业应保持一致

同一企业对所有投资性房地产通常采用同一计量模式。

有特殊分类和准则规定的项目按适用规则处理。

## 七、成本模式和公允价值模式对比

| 项目 | 成本模式 | 公允价值模式 |
|---|---|---|
| 初始计量 | 成本 | 成本 |
| 后续账面基础 | 成本减折旧/摊销、减值 | 公允价值 |
| 折旧/摊销 | 需要 | 不需要 |
| 减值准备 | 按适用规则 | 通常通过公允价值变化反映 |
| 期末公允价值变动 | 不直接调整账面 | 计入当期损益 |
| 模式变更 | 可在满足条件时转公允价值 | 通常不可转回成本模式 |

## 八、考试判断顺序

看到投资性房地产后续计量题：

1. 企业采用什么模式；
2. 如果是成本模式，是否要折旧、摊销或减值；
3. 如果是公允价值模式，年末公允价值是多少；
4. 公允价值差额进哪个损益；
5. 是否发生计量模式变更；
6. 模式变更是否符合规则。

禁止：公允价值模式下继续计提折旧或摊销。
