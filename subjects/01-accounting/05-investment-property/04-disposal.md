# 4. 投资性房地产的出租与处置

## 一句话结论

投资性房地产的日常租金通常计入其他业务收入；出售时将取得的价款确认收入，并结转投资性房地产账面价值和相关累计变动。

## 一、出租期间

取得租金：

```text
借：银行存款 / 应收账款
贷：其他业务收入
```

### 成本模式

建筑物折旧、土地使用权摊销通常计入其他业务成本：

```text
借：其他业务成本
贷：投资性房地产累计折旧 / 投资性房地产累计摊销
```

### 公允价值模式

不计提折旧或摊销。

期末公允价值变化计入公允价值变动损益。

## 二、成本模式投资性房地产出售

出售时通常分两部分：

1. 确认处置收入；
2. 结转投资性房地产账面价值。

例如：

```text
借：银行存款
贷：其他业务收入
```

同时：

```text
借：其他业务成本
    投资性房地产累计折旧/摊销
    投资性房地产减值准备
贷：投资性房地产
```

最终利润取决于处置收入与账面价值等之间的差额。

## 三、公允价值模式投资性房地产出售

出售时确认其他业务收入，并把投资性房地产当前账面价值结转至其他业务成本。

如果以前确认过公允价值变动损益，处置时还要按教材和准则要求结转相关累计公允价值变动，保证处置交易的完整表达。

如果转换日曾因自用房地产或存货转入而确认其他综合收益，处置时还需按规定处理该部分其他综合收益。

## 四、转换形成的其他综合收益

公允价值模式下，自用房地产或存货转为投资性房地产时产生的增值可能计入其他综合收益。

以后处置这项投资性房地产时，该金额需要按准则规定转入与处置有关的损益或成本项目。

考试题如果同时给出：

- 转换日其他综合收益；
- 后续公允价值变动；
- 最终出售；

通常要求把三段处理串起来。

## 五、处置题快速框架

### 成本模式

先算：

`账面价值 = 原始成本 - 累计折旧/摊销 - 减值准备`

再比较处置收入与账面价值及相关支出。

### 公允价值模式

先确认处置日前投资性房地产已经按最新公允价值计量，再处理出售收入、账面价值结转、累计公允价值变动和可能存在的其他综合收益。

## 六、常见陷阱

1. 公允价值模式下仍计提折旧；
2. 出售时只确认收入，不结转账面价值；
3. 漏掉以前确认的公允价值变动；
4. 漏掉转换日形成的其他综合收益；
5. 把投资性房地产出售简单套用固定资产清理流程。

禁止：机械使用“固定资产清理”处理投资性房地产出售。投资性房地产通常按其他业务收入和其他业务成本等相关科目处理。
