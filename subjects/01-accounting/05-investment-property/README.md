# 第五章 投资性房地产

## 本章目标

完成本章后，应能判断一项房地产属于自用固定资产、无形资产、存货还是投资性房地产，并处理成本模式、公允价值模式、用途转换和处置。

2026 CPA 会计大纲对投资性房地产的后续计量模式要求较高，成本模式、公允价值模式及模式变更属于重点。

## 本章主线

先问“企业为什么持有这套房地产”。持有目的决定分类。

- 自己生产经营使用：固定资产或无形资产；
- 房地产企业准备出售：存货；
- 为赚取租金、资本增值或两者兼有：投资性房地产。

分类正确后，再判断后续采用成本模式还是公允价值模式。

## 高频失分点

- 只看资产名称，不看持有目的；
- 把房地产开发企业待售商品房列为投资性房地产；
- 公允价值模式下继续计提折旧或摊销；
- 公允价值变动漏计当期损益；
- 把成本模式转公允价值模式当普通当期损益处理；
- 公允价值模式转换时忽略“公允价值高于账面价值”的其他综合收益处理；
- 认为公允价值模式可以随时改回成本模式。

禁止：先背分录再判断用途。投资性房地产的第一步永远是分类。
