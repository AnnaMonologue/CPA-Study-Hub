# 第二章 存货

## 这一章解决什么问题

存货章回答四个问题：

1. 哪些项目属于存货，取得时按多少钱入账；
2. 一批批成本不同的存货发出去后，如何确定发出成本和期末结存成本；
3. 存货卖价下降或损坏时，是否需要计提跌价准备；
4. 实地盘点发现账实不符时，如何分析和处理。

## 2026 大纲定位

官方大纲包括：

- 存货的性质与确认条件；
- 存货的初始计量；
- 发出存货成本的计量方法；
- 存货成本结转；
- 期末计量与存货跌价准备；
- 可变现净值；
- 清查盘点；
- 列示与披露。

除性质、盘点和披露等基础内容外，计量与跌价部分要求达到应用层级。

## 学完应达到

- 能判断一笔支出是否进入存货成本；
- 会用先进先出法和加权平均思路计算发出成本；
- 会计算可变现净值；
- 会判断是否计提、转回存货跌价准备；
- 能把跌价准备变化与当期损益联系起来；
- 能处理常见盘盈、盘亏判断。

禁止：背“成本与可变现净值孰低”一句话后直接套数字。必须先判断存货用途，再确定可变现净值的计算路径。
