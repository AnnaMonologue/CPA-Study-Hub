## 本章主线

做任何减值题都按四步：

1. 是否需要测试？
2. 账面价值是多少？
3. 可收回金额是多少？
4. 账面价值超过可收回金额多少？

公式：

`减值损失 = 账面价值 - 可收回金额`

其中：

`可收回金额 = 公允价值减去处置费用后的净额 与 预计未来现金流量现值 两者中的较高者`

## 高频失分点

- 两个可收回金额指标取较低值；
- 只在出现明显亏损时才考虑减值；
- 商誉单独计算未来现金流量；
- 资产不能独立产生现金流时仍强行单项测试；
- 资产组减值分摊时先按比例冲普通资产，再冲商誉；
- 分摊后把某项资产账面价值压到准则允许的下限以下；
- 后续价值恢复时把已经确认的固定资产、无形资产等减值准备转回。

不可：看到市场价格下跌就直接确认减值。先计算可收回金额。
