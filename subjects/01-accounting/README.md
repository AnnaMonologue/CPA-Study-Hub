# 01 会计

## 这科在整个 CPA 里的作用

## 后续学习顺序

### A. 基础资产与经营循环

无形资产 → 投资性房地产 → 负债 → 所有者权益 → 收入费用利润 → 财务报告。

目标：能判断资产、负债、权益、收入、费用的变化，并独立写出基础会计处理。

### B. 中级处理

职工薪酬 → 借款费用 → 或有事项 → 政府补助 → 外币折算 → 会计政策估计与差错 → 日后事项。

### C. 核心难点

金融工具 → 长期股权投资 → 企业合并 → 合并财务报表 → 所得税 → 租赁 → 股份支付。

这些模块需要反复做计算分析题和综合题。

禁止：只看笔记不做题。

### D. 独立专题

资产减值、持有待售、非货币性资产交换、债务重组、每股收益、公允价值计量、政府及民间非营利组织会计。

## 学习检查

一个会计知识点达到“会做基础题”，至少需要做到：

1. 能说明业务发生后哪些会计要素变化；
2. 能解释分录每一笔借、贷的原因；
3. 能在题目更换情境后重新判断；
4. 能完成对应章节的基础选择题和计算题。

禁止：只背固定分录模板。
