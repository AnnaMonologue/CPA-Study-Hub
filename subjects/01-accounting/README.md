# 01 会计

定位：CPA 六科的底层语言。目标不是背分录，而是理解业务如何影响资产、负债、所有者权益、收入、费用和报表。

## 主要模块

- 会计基本原理与财务报告
- 存货、固定资产、无形资产、投资性房地产
- 长期股权投资与合营安排
- 资产减值、负债、职工薪酬、股份支付、借款费用、或有事项
- 金融工具、租赁
- 收入、费用、利润、政府补助、所得税
- 非货币性资产交换、债务重组、外币折算
- 会计政策/估计/差错、资产负债表日后事项
- 企业合并与合并财务报表
- 每股收益、公允价值、政府及民间非营利会计等当年大纲内容

## 学习要求

每个分录至少解释：业务事实 → 会计要素变化 → 科目选择 → 借贷方向 → 对报表的影响。

复杂章节不要只刷选择题；长期股权投资、金融工具、所得税、企业合并/合并报表等应逐步进入计算分析和综合题。

> 具体章节名称与范围以 2027 官方大纲为准。
