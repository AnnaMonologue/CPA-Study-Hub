# 01 会计

## 这科在整个 CPA 里的作用

会计是六科的底层语言。审计要读财务报表，税法大量业务也需要理解会计处理。零基础先建立会计框架。

## 当前学习入口

### 00 基础语言
进入 [`00-foundations/`](00-foundations/)。内容：会计记录对象、六大会计要素、会计恒等式、借贷记账法、基础分录和第一组练习。

### 01 第一章：总论
进入 [`01-general/`](01-general/)。内容：财务报告目标、基本假设、权责发生制、信息质量要求、计量属性、财务报告、可持续信息披露、AI 应用和章节练习。

### 02 第二章：存货
进入 [`02-inventory/`](02-inventory/)。内容：存货确认、初始成本、发出计量、成本结转、可变现净值、跌价准备与转回、清查和综合练习。

### 03 第三章：固定资产
进入 [`03-fixed-assets/`](03-fixed-assets/)。内容：确认与初始计量、四种折旧方法、折旧起止时间、更新改造、日常维修、出售、报废毁损、盘盈盘亏和综合练习。

### 04 第四章：无形资产
进入 [`04-intangible-assets/`](04-intangible-assets/)。内容：定义与初始计量、土地使用权、内部研发费用化与资本化、使用寿命、摊销、减值、出售出租报废和综合练习。

### 05 第五章：投资性房地产
进入 [`05-investment-property/`](05-investment-property/)。内容：范围与持有目的判断、初始计量、成本模式、公允价值模式、模式变更、用途转换、转换差额、出租出售以及综合练习。

### 06 第六章：长期股权投资与合营安排
进入 [`06-long-term-equity-and-joint-arrangements/`](06-long-term-equity-and-joint-arrangements/)。内容：控制、共同控制、重大影响，初始计量，成本法，权益法，净利润调整，现金股利，其他综合收益，其他权益变动，超额亏损，核算方法转换，处置，共同经营、合营企业及综合练习。

### 07 第七章：资产减值
进入 [`07-asset-impairment/`](07-asset-impairment/)。内容：减值迹象、年度测试、可收回金额、未来现金流量现值、减值损失、后续折旧摊销、不得转回规则、资产组、总部资产、商誉减值、减值分摊和综合练习。

### 08 第八章：负债
进入 [`08-liabilities/`](08-liabilities/)。

内容：

1. 流动负债判断；
2. 短期借款；
3. 应付票据与应付账款；
4. 商业折扣、现金折扣基础；
5. 合同负债和一年内到期非流动负债；
6. 应交税费、增值税进项与销项基础；
7. 长期借款；
8. 一般公司债券和实际利率法；
9. 折价、溢价债券摊余成本；
10. 可转换公司债券负债与权益拆分；
11. 章节计算练习与解析。

税率、税收优惠及具体年度税收政策统一按目标考季官方口径核验。

## 后续学习顺序

### A. 下一阶段

职工薪酬 → 股份支付 → 借款费用 → 或有事项。

### B. 金融与经营核心

金融工具 → 租赁 → 持有待售 → 所有者权益 → 收入费用利润 → 政府补助 → 所得税。

### C. 综合与高难度

非货币性资产交换 → 债务重组 → 外币折算 → 财务报告 → 会计政策估计与差错 → 日后事项 → 企业合并 → 合并财务报表 → 每股收益 → 公允价值计量。

这些模块需要反复做计算分析题和综合题。

禁止：只看笔记不做题。

## 学习检查

一个会计知识点达到“会做基础题”，至少需要做到：

1. 能说明业务发生后哪些会计要素变化；
2. 能解释分录每一笔借、贷的原因；
3. 能在题目更换情境后重新判断；
4. 能完成对应章节的基础选择题和计算题。

禁止：只背固定分录模板。
