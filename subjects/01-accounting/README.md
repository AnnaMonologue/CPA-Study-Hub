# 01 会计

## 这科在整个 CPA 里的作用

会计是六科的底层语言。审计要读财务报表，税法大量业务也需要理解会计处理。零基础先建立会计框架。

## 后续学习顺序

### A. 下一阶段

持有待售 → 所有者权益 → 收入费用利润。

### B. 经营与税会衔接

政府补助 → 所得税 → 非货币性资产交换 → 债务重组。

### C. 综合与高难度

外币折算 → 财务报告 → 会计政策估计与差错 → 日后事项 → 企业合并 → 合并财务报表 → 每股收益 → 公允价值计量 → 政府及民间非营利组织会计。

这些模块需要反复做计算分析题和综合题。

禁止：只看笔记不做题。

## 学习检查

一个会计知识点达到“会做基础题”，至少需要做到：

1. 能说明业务发生后哪些会计要素变化；
2. 能解释分录每一笔借、贷的原因；
3. 能在题目更换情境后重新判断；
4. 能完成对应章节的基础选择题和计算题。

禁止：只背固定分录模板。
