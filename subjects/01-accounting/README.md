# 01 会计

## 这科在整个 CPA 里的作用

会计是六科的底层语言。审计要读财务报表，税法大量业务也需要理解会计处理。零基础先建立会计框架。

## 当前学习入口

### 00 基础语言

进入 [`00-foundations/`](00-foundations/)。

内容：会计记录对象、六大会计要素、会计恒等式、借贷记账法、基础分录和第一组练习。

### 01 第一章：总论

进入 [`01-general/`](01-general/)。

内容：财务报告目标、基本假设、权责发生制、信息质量要求、计量属性、财务报告、可持续信息披露、AI 应用和章节练习。

### 02 第二章：存货

进入 [`02-inventory/`](02-inventory/)。

内容：存货确认、初始成本、发出计量、成本结转、可变现净值、跌价准备与转回、清查和综合练习。

### 03 第三章：固定资产

进入 [`03-fixed-assets/`](03-fixed-assets/)。

内容：确认与初始计量、四种折旧方法、折旧起止时间、更新改造、日常维修、出售、报废毁损、盘盈盘亏和综合练习。

### 04 第四章：无形资产

进入 [`04-intangible-assets/`](04-intangible-assets/)。

内容：

1. 无形资产定义、可辨认性与初始计量；
2. 土地使用权等特殊分类；
3. 研究阶段费用化；
4. 开发支出资本化的完整条件；
5. 使用寿命有限与不确定无形资产；
6. 摊销起止时间、净残值和减值；
7. 出售、出租、报废；
8. 章节练习与综合题解析。

## 后续学习顺序

### A. 基础资产与经营循环

投资性房地产 → 负债 → 所有者权益 → 收入费用利润 → 财务报告。

目标：能判断资产、负债、权益、收入、费用的变化，并独立写出基础会计处理。

### B. 中级处理

职工薪酬 → 借款费用 → 或有事项 → 政府补助 → 外币折算 → 会计政策估计与差错 → 日后事项。

### C. 核心难点

金融工具 → 长期股权投资 → 企业合并 → 合并财务报表 → 所得税 → 租赁 → 股份支付。

这些模块需要反复做计算分析题和综合题。

禁止：只看笔记不做题。

### D. 独立专题

资产减值、持有待售、非货币性资产交换、债务重组、每股收益、公允价值计量、政府及民间非营利组织会计。

## 学习检查

一个会计知识点达到“会做基础题”，至少需要做到：

1. 能说明业务发生后哪些会计要素变化；
2. 能解释分录每一笔借、贷的原因；
3. 能在题目更换情境后重新判断；
4. 能完成对应章节的基础选择题和计算题。

禁止：只背固定分录模板。
