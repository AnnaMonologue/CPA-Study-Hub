# 00 会计基础语言

这是 CPA 会计的起点模块。完成后再进入存货、固定资产等具体章节。

## 学习目标

完成本模块后，应能独立完成以下任务：

- 用一句话解释会计在记录什么；
- 判断一项业务影响资产、负债、所有者权益、收入、费用中的哪些项目；
- 用 `资产 = 负债 + 所有者权益` 检查业务记录是否合理；
- 判断常见账户的借贷方向；
- 写出最基础的会计分录，并解释每一笔借贷的原因；
- 区分“收到/付出现金”和“确认收入/费用”的时间。

## 考纲位置

对应 2026 CPA《会计》大纲第一部分“总论”，涉及会计概述、财务报告目标、会计基本假设、会计基础、会计信息质量要求、会计要素及其确认和计量、财务报告等内容。

当前目标考季为 2027。2026 大纲用于预习定位；2027 官方大纲发布后再核对变化。

## 通过标准

学完后随机给出一笔简单业务，你至少要能回答：

1. 发生了什么经济变化？
2. 哪些会计要素增加或减少？
3. 哪些科目记借方，哪些科目记贷方？
4. 为什么这样记？

达到这一步，再进入具体资产与负债章节。
