# 第十一章 借款费用

## 本章目标

完成本章后，应能判断哪些资产符合资本化条件，确定借款费用开始、暂停和停止资本化的时点，并计算专门借款、一般借款及外币专门借款的资本化金额。

## 学习顺序

1. [`01-scope-and-capitalization-period.md`](01-scope-and-capitalization-period.md)：借款费用范围、符合资本化条件的资产、开始/暂停/停止时点。
2. [`02-measurement.md`](02-measurement.md)：专门借款、一般借款、辅助费用和外币借款。
3. [`03-practice.md`](03-practice.md)：章节练习。
4. [`04-answers.md`](04-answers.md)：答案与错因分析。

## 本章主线

借款费用题先解决两个问题：

1. 这段时间是否处于资本化期间？
2. 这笔借款属于专门借款还是一般借款？

然后再计算金额。

## 三个开始条件

借款费用同时满足以下条件才开始资本化：

- 资产支出已经发生；
- 借款费用已经发生；
- 为使资产达到预定可使用或可销售状态所必要的购建或生产活动已经开始。

## 高频失分点

- 借款到账就立即开始资本化；
- 只发生预付款但供应商尚未开始必要生产活动时仍直接资本化；
- 正常施工停顿也暂停资本化；
- 非正常中断未连续超过三个月就暂停；
- 资产已经达到预定可使用状态仍继续资本化；
- 专门借款资本化金额忘减闲置资金利息收入或投资收益；
- 一般借款把全部利息都资本化；
- 一般借款资本化额超过实际发生的相关借款利息。

禁止：先算利息再判断期间。先确定资本化期间。
