# 06 税法

## 核心思路

税法同时考“规则记忆”和“计算链条”。必须把纳税人、征税范围、计税依据、税率/征收率、扣除、优惠、申报缴纳串成一条完整流程。

## 推荐学习顺序

### 第一优先级
1. 增值税；
2. 企业所得税；
3. 个人所得税。

### 第二优先级
4. 消费税；
5. 土地增值税；
6. 关税等需要计算的税种。

### 第三优先级
7. 房产、契税、资源、环保、车购、车船、印花等小税种；
8. 国际税收；
9. 税收征管与税务行政法制。

## 年度更新提醒

税法是本仓库年度更新优先级最高的科目。2026 的税率、优惠、扣除口径只能用于 2026 基线理解；2027 备考必须逐项核验。
