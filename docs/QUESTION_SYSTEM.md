# CPA 做题系统

本文件规定 AI 出题、解析和错题归因的方法。目标不是制造偏题怪题，而是让学习者在不同题目包装下认出同一个考点。

## 按科目匹配题型

| 科目 | 训练题型 | 默认用法 |
|---|---|---|
| 会计 | 单选、多选、计算分析、综合 | 基础概念用选择；计量/分录用计算分析；跨章节用综合 |
| 审计 | 单选、多选、简答、综合 | 概念用选择；程序/意见判断用简答；跨流程用综合 |
| 财管 | 单选、多选、计算分析、综合 | 公式应用必须动手算；多步骤决策用综合 |
| 战略 | 单选、多选、简答、综合案例 | 框架识别用选择；企业背景用案例 |
| 经济法 | 单选、多选、案例分析 | 规则识别用选择；事实代入用案例 |
| 税法 | 单选、多选、计算分析、综合 | 规则用选择；税额计算用计算分析；多税种串联用综合 |

## 默认出题流程

1. 先确定知识点和训练目标；
2. 默认先出 3 题，不立即给答案；
3. 学习者作答后再解析；
4. 每题解析必须包含：正确结论 → 推理/计算过程 → 错误选项为什么错 → 一句话考点复述；
5. 如果答错，判断错因是否需要进入错题本或薄弱点。

## 好的干扰项

错误选项必须对应真实常见错误，而不是随机编一个荒谬答案。

常见错误类型：

- 会计：确认时点错、借贷方向错、计量属性错、漏抵销/漏递延所得税；
- 财管：期数错、公式适用条件错、税前税后混淆、单位/年化转换错；
- 税法：征税范围错、税率/扣除口径错、进项抵扣判断错、计税依据错；
- 审计：认定与程序不匹配、保证程度混淆、意见类型判断错；
- 经济法：构成要件漏项、一般规则与例外混淆、期限/比例记错；
- 战略：模型名认得但题干证据匹配错、只贴标签不解释。

## 难度层级

- L1：理解——以选择题为主；
- L2：应用——简答/计算分析；
- L3：综合——长案例、跨章节或多步骤问题。

第一次学习默认 L1 + 少量 L2；章节完成后加入 L2；进入应试状态再大量使用 L3。

## 错题归因代码

- `C` Concept：概念不懂；
- `M` Memory：规则/法条/公式记错；
- `A` Application：会背但不会代入；
- `R` Reading：漏看或误读题干条件；
- `K` Calculation：计算/单位/符号错误；
- `T` Time：时间分配问题；
- `U` Update：使用了过期法规或旧口径。

错题记录优先保存“为什么错”和“下次看到什么信号应该触发什么规则”，不抄整段标准答案。
