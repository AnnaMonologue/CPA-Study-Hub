# 六科学习顺序

## 默认路线（零基础）

### 第一阶段：先建立底层语言
1. **会计**：先学基础概念、资产负债、收入费用，再进入金融工具、长投、合并等难点。
2. **税法**：会计基础形成后同步切入，先抓增值税、企业所得税、个人所得税三大主力税种。

### 第二阶段：在会计基础上扩展
3. **审计**：理解财务报表、认定、业务循环后学习风险导向审计会顺很多。
4. **财务成本管理**：单独建立公式与计算训练线，不要只看讲解不动手算。

### 第三阶段：框架与案例
5. **经济法**：按“规则 → 构成要件 → 案例代入”学习。
6. **公司战略与风险管理**：最后集中整理框架、案例识别与答题表达。

## 不等于考试报考顺序

学习顺序只是为了降低理解成本。实际每年报考几科，要根据可投入时间、基础和当年目标另定。

## 每个模块的状态标准

- `0 未开始`：没有系统学过；
- `1 已理解`：能用自己的话解释；
- `2 会做基础题`：典型选择/基础计算稳定；
- `3 可应试`：综合题、案例或复杂计算达到稳定正确率。

不要因为“看完视频/看完笔记”就把状态标成 2 或 3。状态由输出能力和做题结果决定。
