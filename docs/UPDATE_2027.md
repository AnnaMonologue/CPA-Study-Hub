# 2027 考季更新清单

目标：2027 官方资料发布后，只更新变化部分，不重建整个仓库。

## Gate 1 — 官方文件到位

- [ ] 2027 CPA 全国统一考试大纲
- [ ] 2027 报名简章
- [ ] 2027 考试时间/报名/缴费公告
- [ ] 2027 官方教材信息
- [ ] 税法、经济法涉及的重要新法/新规生效口径

每项必须保存：标题、发布机构、发布日期、官方链接。

## Gate 2 — 大纲差异

逐科建立 2026 → 2027 diff：

- [ ] 新增考点
- [ ] 删除考点
- [ ] 名称调整
- [ ] 能力等级变化
- [ ] 法规截止日期/适用口径变化
- [ ] 明显新增热点

## Gate 3 — 优先更新高波动科目

顺序默认：

1. 税法
2. 经济法
3. 会计/审计中受准则与监管变化影响的部分
4. 战略
5. 财管

这只是“年度变动检查顺序”，不是学习科目顺序。

## Gate 4 — 清理旧标记

更新某一知识点后：

- [ ] 删除或替换 `待2027核验`
- [ ] 在对应科目 README 记录变化
- [ ] 如旧错题受规则变化影响，标记“历史口径”，不要直接删除
- [ ] 更新 `progress/PROGRESS.md` 的目标考季版本信息

## 禁止

- 禁止把 2026 税率/法条自动当成 2027；
- 禁止只看培训机构“变化总结”而不回到官方文件；
- 禁止为了更新而删除旧错题的学习价值；
- 禁止把来源年份不明的 GitHub 笔记标成 2027 内容。
