# 资料来源与版权边界

本仓库采用“引用上游、重建结构、不整库搬运正文”的策略。

## 官方来源

考试范围、报名与政策以中国注册会计师协会（CICPA）当年正式发布的信息为最高优先级。

- 中注协官网：https://www.cicpa.org.cn/
- 注册会计师全国统一考试网上报名系统：https://cpaexam.cicpa.org.cn/

2027 文件发布后，应把具体公告和大纲链接记录到 `syllabus/README.md`。

## 不进入公开仓库的内容

- 购买的 CPA 教材全文或扫描件；
- 付费网课讲义、机构内部题库；
- 来路不明的“破解/盗版资料包”；
- 自购资料转换后的全文文本。

这些资料如用于 AI 辅助学习，应只放本地 `corpus/` 或 `private/`，二者均被 `.gitignore` 排除。

## 可以长期保存的内容

- 自己写的知识总结；
- 自己做题后的错因分析；
- 自己制作的公式卡、知识地图；
- 官方公开大纲的索引与链接；
- 符合原许可条件的开放资料。
