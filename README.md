# CPA Study Hub

一个面向中国注册会计师（CPA）专业阶段的长期自学仓库。

本仓库不复制商业教材、网课讲义或受版权保护的题库。它把公开项目中最有价值的**学习结构**重新组合成自己的系统：

- **考试骨架**：按 CPA 六科组织，优先以中注协当年官方考试大纲为准。
- **AI 辅导流程**：零基础解释 → 考纲定位 → 例题/练习 → 错题 → 薄弱点 → 复习。
- **长期记录**：进度、错题和薄弱知识点与知识正文分离。
- **年度更新**：2026 内容仅作过渡基线；2027 官方大纲发布后按差异更新，不整库重做。

## 怎么用

第一次学某个知识点时，按以下顺序：

1. 进入对应 `subjects/` 科目目录确认知识位置。
2. 对照目标考季官方大纲确认是否在考试范围，以及要求掌握到什么程度。
3. 让 AI 按 `AGENTS.md` 的格式讲解，不直接堆术语。
4. 学完做针对性练习。
5. 做错才进入 `WRONG_ANSWERS.md`；反复出错或理解不稳再进入 `WEAKNESS.md`。
6. `PROGRESS.md` 记录章节状态，不把大量正文塞进进度表。

## 资料策略

这个仓库是“学习操作系统”，不是盗版教材合集。正文知识优先来自：

1. 中注协当年官方考试大纲、报名简章及公告；
2. 自己合法持有的教材/讲义；
3. 公开、许可明确的学习资料；
4. AI 辅助解释与自己整理的笔记。

上游项目与版权说明见 [`docs/SOURCES.md`](docs/SOURCES.md)。

## 初会与 CPA 分工

本仓库只做 CPA。初级会计采用更轻量的路线：B站系统课 + 免费题库/真题 + 当年官方考纲，不与 CPA 六科知识库混在一起。
