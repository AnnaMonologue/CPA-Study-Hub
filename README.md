# CPA-Study-Hub

面向中国注册会计师（CPA）专业阶段的长期自学仓库。目标考季为 **2027**；在 2027 官方大纲发布前，以 2026 官方大纲与公开资料作为预习基线。

本仓库用于构建可持续更新的 **CPA 学习操作系统**：

- 六科知识地图：告诉你先学什么、各模块之间怎么连接；
- AI Tutor 规则：零基础解释 → 考纲定位 → 练习 → 错题 → 薄弱点 → 复习；
- 学习追踪：章节状态、错题、薄弱点分开保存；
- 年度升级：2027 大纲发布后只更新变化。

禁止：把商业教材、付费讲义、受版权保护的题库整段复制到公开仓库。

## 最简单的使用方式

直接对 AI 说：

> 开始学 CPA 会计。先读本仓库 AGENTS.md、syllabus/2026/CURRICULUM_MAP.md 和 subjects/01-accounting/README.md，从适合零基础的第一模块开始讲。

学完后再说：

> 记录今天的学习进度。

只有在你明确要求记录时，才修改 `progress/`。

## 资料优先级

1. 目标考季中注协官方考试大纲、报名简章、公告及现行法规；
2. 自己合法持有的当年教材/讲义；
3. 本仓库已核验且注明年份的笔记；
4. 许可明确的公开资料；
5. AI 通用知识。

税率、税收优惠、具体法条、监管口径等内容在 2027 官方资料发布前必须视为 `待2027核验`。

## 初会与 CPA 分工

本仓库只负责 CPA。初级会计采用更轻量的路线：B站系统课 + 当年免费题库/真题 + 官方考纲。
